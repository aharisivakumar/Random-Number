# Random-Number
live link : [https://random-number-three-phi.vercel.app/]

Random Number Generator

A simple React application that generates a random number when the user clicks a button. This project helps beginners understand React components, state management, and event handling.

Features

- Generate a random number with a single click
- Instant display of the generated number
- Simple and responsive user interface
- Built using React functional components and Hooks

Technologies Used

- React
- JavaScript (ES6)
- HTML5
- CSS3

Getting Started

1. Clone the repository:
   
   git clone <repository-url>

2. Navigate to the project folder:
   
   cd random-number-generator

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm start

5. Open your browser and visit 

How It Works

- Click the Generate Random Number button.
- A random number is generated using JavaScript's "Math.random()" function.
- The generated number is displayed instantly on the screen.

Learning Outcomes

- React functional components
- "useState" Hook
- Event handling with "onClick"
- Updating the UI dynamically
- Basic CSS styling
